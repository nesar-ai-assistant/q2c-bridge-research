# Q2C Bridge Research\n\nQuarks-to-Cosmos: Bridging Particle Physics and Cosmology with AI\n\nSystematic knowledge base and executable tools for multi-scale physics bridging topics.\n\n## Topics\n\n1. **Big Bang Nucleosynthesis (BBN)** - Primordial abundances, neutron lifetime puzzle, dark radiation\n2. **Sterile Neutrinos** - keV-MeV dark matter, cosmological constraints, direct detection\n3. **Modified Gravity / Dark Energy** - f(R), Horndeski, w0waCDM, screening mechanisms\n4. **Dark Matter Cross-Scale** - WIMP phenomenology, direct detection ↔ relic abundance\n5. **Neutrino Mass & Cosmology** - Active neutrino mass from LSS, Neff constraints\n6. **AI Agents for Multi-Scale Physics** - ArgoLOOM, MCP servers, multi-agent orchestration\n\n## Structure\n\n- `summaries/` — Topic summaries with references and tool inventories\n- `tools/` — Inventory of existing codes and their capabilities\n- `notebooks/` — Jupyter notebooks with executable demonstrations\n- `mcp_servers/` — MCP server implementations for bridging tools\n- `weekly_updates/` — Weekly research update logs\n\n## Related Work\n\n- [ArgoLOOM](https://github.com/ML4HEP-Theory/ArgoLOOM) (arXiv:2510.02426)\n- [bbn-mcp-server](https://github.com/nesar/bbn-mcp-server)\n- [HEP-KE org](https://github.com/HEP-KE)\n
